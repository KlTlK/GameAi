# Velvet Roulette Club

Атмосферная 3D-рулетка на виртуальные фишки. Игра работает целиком в браузере: сервер и регистрация не нужны. Фишки не имеют денежной ценности, баланс и история сохраняются в текущем браузере.

## Запуск локально

Нужен Node.js 20 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для проверки production-сборки: `npm run build`, затем `npm run preview`.

## Публикация на GitHub Pages

1. В настройках репозитория откройте **Settings → Pages** и в разделе **Build and deployment → Source** выберите **GitHub Actions**.
2. Добавьте изменения в ветку `main` (например, через pull request). После каждого обновления `main` workflow автоматически собирает и публикует игру. Его также можно запустить вручную во вкладке **Actions → Deploy to GitHub Pages**.
3. После завершения workflow игра будет доступна по адресу `https://kltlk.github.io/GameAi/` (или по адресу, показанному в настройках Pages).

Для вложенного пути репозитория используются относительные адреса ресурсов, поэтому отдельная настройка base URL не требуется.
